# ネット予約システム（テンプレート版）— 仕組みと設定

焼肉モランボン用に作ったネット予約を、他のお店にも入れられるようにしたものです。
**お店ごとに変えるのは `functions/shop.config.js` だけ**（＋ロゴ画像と色）。月額0円（Cloudflare 無料プラン＋Gmail）。

- 新しいお店に入れる手順 → [`導入手順.md`](導入手順.md)
- 売るときに決めておくこと → [`販売時の決めごと.md`](販売時の決めごと.md)

| パス | 内容 |
|---|---|
| `/reserve/` | お客さん向け予約画面 |
| `/reserve/cancel/` | キャンセル画面（予約番号＋電話番号） |
| `/admin/` | 管理画面（パスワード付き） |
| `/privacy/` | 個人情報の取り扱い（中身は設定ファイルから。**公開前にお店と確認**） |
| `functions/shop.config.js` | **お店ごとの設定**（サイトとしては公開されない） |
| `functions/api/…` | API（Pages Functions）。`/api/config` は画面用に設定の一部を返す |
| `setup/` | SQL・Apps Script・確認用スクリプト。サイトとしては公開されない（404） |

## 1. 設定ファイル（`functions/shop.config.js`）

| 項目 | 内容 |
|---|---|
| `shop` | 店名・電話番号・住所・サイトURL |
| `brand` | ロゴ・タブのアイコン・テーマ色・見出しの下の小さな文字 |
| `hours` | 営業時間（予約表の範囲）と、マスの刻み（15／30／60分） |
| `closedDays` | 定休日。`{ weekday: '月' }`＝毎週、`{ weekday: '火', nth: 2 }`＝第2、`nth: -1`＝最終 |
| `web.slots` | ネットで受け付ける来店時刻 |
| `web.stayMinutes` | 滞在時間（2時間制なら 120） |
| `web.sameDayDeadlineMinutes` | 当日予約の締め切り（来店の何分前まで） |
| `web.cancelDaysBefore` | ネットでキャンセルできる期限（1＝前日23:59まで、0＝当日の締め切りまで） |
| `web.maxParty` | ネットで受ける最大人数（1〜6） |
| `web.phoneOnly` | 「お電話で」の案内に足す文言（人数・時間は自動） |
| `dataRetentionDays` | 予約データを残す日数（来店日から） |
| `mail` | お客さん宛メールの件名・本文・署名（`{店名}` `{予約内容}` などが置き換わる） |
| `privacy` | 個人情報ページの事業者名・制定日・追加の利用目的 |

書き換えたら、必ず確認する：

```sh
node setup/check-config.mjs     # 間違いがないか、画面に出る文章・定休日・メールの例を表示
```

設定に間違いがあると、予約の API が動かなくなる（デプロイ自体が失敗することもある）。わざとそうしている（間違ったルールのまま予約を受けないため）。

**設定ファイルでは変えられないもの**（変えるときはコードを直す＝別見積もり）
- ネット予約の卓は **4人卓・6人卓の2種類**（1〜4名→4人卓、5〜6名→6人卓）。2人卓・カウンターなどは電話予約の卓としてだけ使える
- 色・フォント：`reserve/reserve.css` の `:root`。ロゴ：`/images/logo.png`（設定の `brand.logo` で別の場所も可）
- 個人情報ページの文章そのもの：`privacy/index.html`
- 深夜0時をまたぐ営業

## 2. 卓とネットの枠（お店が管理画面で変える）

- 「設定」タブ：卓の名前・人数・並び順・ネットに使うか、ネットに出す卓数（4人卓／6人卓）、何日先まで受け付けるか
- 最初の卓の一覧は `setup/migrations/0002_tables.sql` に入っている（モランボンの例）。導入後に管理画面で合わせる
- ネットの残り＝「ネットに出す卓数の残り」と「実際に空いている卓の数」の少ない方。電話予約で卓が埋まるとネットも満席になる
- 空き確認と作成は **1つの条件付き INSERT** で行うので、同時に予約が来ても上限を超えない

## 3. メール（Google Apps Script）

- 件名・本文は Cloudflare 側（`functions/_lib/mail.js`）で設定ファイルから組み立てて、Apps Script に送る
- `setup/gas/Code.gs` は **どのお店でも同じファイル**。お店ごとに書き換えない
- Gmail の送信上限は無料アカウントで 1日100通ほど。1件の予約で最大3通（確認・お店への通知・前日リマインド）なので、**1日30件程度まで**が目安
  - 前日リマインドは、新しい予約の確認メール用に20通を残して送る
  - 送れなかったメールは記録して、次の前日リマインドのときにお店へまとめて知らせる
- 古い Apps Script（モランボン v1）でも動くように、通知には予約データ（`booking`）も入れている

## 4. ローカルで確認する

```sh
node setup/check-config.mjs
node setup/dev/server.mjs --memory      # http://127.0.0.1:8788/  管理画面のパスワード：moranbon-dev
node --test setup/dev/test.mjs          # ルール・DBのテスト
BASE=http://127.0.0.1:8788 node --test setup/dev/test.mjs   # API のテストも（サーバー起動中に）
```

- Node.js 22 以上が必要（D1 の代わりに node:sqlite を使う）。メールは送らず、`http://127.0.0.1:8788/__gas` に届いた中身が見られる
- テストの大半はモランボンの設定（17:30〜19:30・2時間制など）が前提。**別のお店の設定にすると自動でスキップ**され、最後の「どの設定でも通るテスト」だけが動く

## 5. コードの場所

- `functions/_lib/config.js`：設定の読み込み・チェック・画面やメールで使う文章づくり
- `functions/_lib/rules.js`：営業時間・滞在時間・定休日・当日の締め切り・キャンセル期限・入力チェック
- `functions/_lib/db.js`：空き計算・予約作成・卓の割り当て・電話予約
- `functions/_lib/mail.js`：メールの件名・本文
- `reserve/shop.js`：画面に店名・電話番号・ルールの文章を入れる（`data-shop="…"`）

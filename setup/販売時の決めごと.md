# 「予約システム付きプラン」販売時の決めごと（たたき台）

YU DESIGN のホームページ制作（月額0円・買い切り）に、ネット予約を足して売るときに、先に決めておくことのまとめ。
**［決める］** の項目は、料金表・約款に入れる前に決める。

---

## 1. 何を売るか（含まれるもの）

- お客さん向け予約画面（日付→時間→人数→入力）、キャンセル画面
- お店向け管理画面：予約表（電話予約の手入力・ドラッグで移動）、一覧、休業・貸切、ネットに出す卓数、卓の設定
- メール：予約確認・キャンセル・前日リマインド（お客さん宛）、予約・キャンセルの通知（お店宛）
- 個人情報の取り扱いページ
- 導入作業一式（設定・Cloudflare・メール送信の設定、動作確認、使い方の説明）
- **月額0円**（Cloudflare 無料プラン＋お店の Gmail）。予約手数料なし

### 設定だけで合わせられるもの（追加料金なし）
店名・連絡先、営業時間、定休日（毎週／第◯／最終◯曜日）、来店時刻の枠、滞在時間、当日の締め切り、キャンセル期限、最大人数（6名まで）、メールの文面、色とロゴ

### 別見積もりにするもの
- 4人卓・6人卓以外の卓をネットに出す（2人卓・カウンター中心のお店）
- コース・メニューの選択、事前決済・キャンセル料の請求
- LINE での通知、Google カレンダーとの連携
- 深夜0時をまたぐ営業、複数店舗
- ネイルサロンなど「卓」ではなく「スタッフの空き時間」で受けるお店（仕組みが別）

## 2. 料金 ［決める］

| 案 | 内容 | 金額（税込） |
|---|---|---|
| 予約システム付きプラン | STANDARD のホームページ＋ネット予約 | 99,000〜132,000円 |
| 追加オプション | 既存サイト（YU DESIGN 制作）にネット予約を追加 | 44,000〜66,000円 |
| モニター価格 | 最初の数店（実績づくり） | 上記の約3分の1引き |

- 根拠の言い方：グルメサイトのネット予約は 1人あたり手数料がかかる。月額も手数料もゼロなので、1年使えば元が取れる
- 支払い：全額前払い（今の方針どおり）
- ［決める］モニターの店数と、実績として掲載してよいか（約款の掲載承諾と同じ扱い）

## 3. 保守の範囲 ［決める］

| 期間・内容 | 案 |
|---|---|
| 不具合の無償修正 | 納品後 **3か月**（YU DESIGN の作ったものが原因の不具合だけ） |
| 設定の変更（営業時間・定休日・来店時刻・メール文面など） | スポット修正 **3,300円／回**（今の料金表と同じ） |
| お店が自分でできること（無料） | 休業・貸切、ネットに出す卓数、卓の追加・名前変更、何日先まで受け付けるか、予約の取り消し・移動 |
| Google・Cloudflare の仕様変更への対応 | 保証期間内でも **有償**（見積もり）。重大なものは事前に連絡 |
| 管理画面のパスワード変更・忘れ | スポット修正扱い |

- 月額の保守契約はしない（制作専門型の方針どおり）。「困ったらスポットで」
- ［決める］保証期間が終わったら、お店の Cloudflare と Apps Script から YU DESIGN を外すか、残すか
  - 外す：お店の持ち物として完全に引き渡す。以後の修正は、そのつど招待してもらう
  - 残す：すぐ直せるが、「YU DESIGN がいつでも予約データを見られる」状態になる。約款に書いて同意をもらう

## 4. メール送信数の上限への対応

- 無料の Gmail から Apps Script で送れるのは **1日100通ほど**
- 1件の予約で最大3通（確認・お店への通知・前日リマインド）、キャンセルで＋2通 → **1日30件程度**のネット予約までは問題なし
- システム側の対策（実装済み）
  - 前日リマインドは、新しい予約の確認メール用に20通を残して送る
  - 送れなかったメールは記録し、翌日お店にまとめて知らせる（お店から電話でフォロー）
- それを超えるお店への案内 ［決める］
  - お店が Google Workspace（有料・お店の負担）に切り替えると、1日1,500通ほどまで送れる
  - または、お店宛の通知メールをやめて管理画面で確認してもらう（設定の変更＝スポット修正）
- 説明するときの言い方：「ネット予約が1日30件を超えるようになったら、ご相談ください」

## 5. 約款・説明で押さえること ［決める］

- **予約の取りこぼし・メールの不達による損害は補償しない**（無料のサービスの組み合わせで動いているため）。障害のときは電話で受けてもらう
- Cloudflare・Google の障害や仕様変更による停止は、YU DESIGN の責任の範囲外
- 個人情報：予約データの持ち主（管理者）は **お店**。YU DESIGN は設定・修正のときだけ扱う。個人情報ページの内容はお店に確認してもらう
- アカウント：Cloudflare・Google はお店の名義。YU DESIGN はメンバーとして招待してもらう（パスワードは預からない）
- GitHub のリポジトリ（サイトのコード）は YU DESIGN が管理する。［決める］解約・引き渡しを希望されたときの扱い（無料で渡す／有償）
- 予約データの保存期間（初期値：来店日から1年で自動削除）

## 6. 導入前にお店に確認すること（ヒアリングに追加）

1. 今の予約の受け方（電話・DM・グルメサイト）と、1日のおおよその予約件数
2. 営業時間・定休日（祝日の扱い）
3. ネットで受けたい来店時刻、滞在時間、当日の締め切り、キャンセル期限
4. 卓の構成と、ネットに出してよい卓数（電話の分は残す）
5. ネットで受ける最大人数と、それ以上・宴会の案内
6. 予約通知を受け取るメールアドレス、管理画面を見る人（スマホで見られるか）
7. Cloudflare・Google のアカウントをお店で作れるか（作れない場合は LINE で手順を案内）
8. 個人情報ページの事業者名
